# 444Store - Modern Roblox & Game Items Marketplace ⚡

Platform e-commerce & top up game modern dengan estetika dark minimalis terinspirasi dari layout Takapedia dan fitur Kingblox, mengusung warna aksen utama **`#85effe` (Electric Cyan)**.

---

## 🚀 Fitur Unggulan

- **🎨 Desain Modern & Clean:**
  - Terinspirasi dari kesederhanaan dan kejelasan alur **Takapedia** (tanpa layout bertumpuk yang membingungkan).
  - Skema warna elegan: latar gelap pekat (`#07090e`) dipadukan dengan aksen neon `#85effe` dan badge informatif.
  - Tipografi tajam menggunakan *Plus Jakarta Sans*.

- **⚡ Order Robux 3 Langkah Cepat:**
  1. **Data Akun:** Input Username Roblox & Nomor WhatsApp untuk konfirmasi otomatis.
  2. **Pilihan Nominal Fleksibel:** Quick button nominal terpopuler (50, 100, 200, 400, 800, dst) + Slider interaktif untuk jumlah custom.
  3. **Metode Pembayaran:** QRIS Realtime, E-Wallet (DANA/OVO/GoPay), dan Virtual Account.
  - **Sticky Order Summary:** Kartu rincian pesanan melayang di samping yang selalu mengupdate total harga secara realtime.

- **🎮 Katalog Gamepass & Item Roblox:**
  - Grid game populer: *Blox Fruits, Fish It, CDID, Evade, Sawah Indo, dll*.
  - Search bar game instan & filter kategori.

- **🔍 Fitur Lacak Pesanan (Track Order):**
  - Cek progres transaksi berdasarkan Invoice ID.

- **⭐ Testimoni Pelanggan & FAQ Interaktif:**
  - Ulasan transparan dari pembeli dan jawaban atas pertanyaan umum terkait keamanan transaksi.

---

## 🛠️ Tech Stack

- **Framework:** React 18 + Vite
- **Styling:** Tailwind CSS + Custom Neon Glow Utilites
- **Icons:** Lucide React
- **Language:** TypeScript

## 💻 Jalankan di Lokal

```bash
# Install dependencies
npm install

# Jalankan server development
npm run dev

# Build untuk production (Vercel / Cloudflare Pages)

```
